# DeepShield — Model Training Guide

Everything about how the models were built, what data was used, and how to train them yourself.

---

## Image Deepfake Model

### Architecture

The model is called **DeepShieldModel** and has three parts that work together:

```
Input image (224×224)
        │
        ├──► EfficientNet-B4 backbone  →  spatial features (1792-dim)
        │         └── CBAM attention applied on top
        │
        └──► FFT Branch  →  frequency features (128-dim)
                  (runs FFT on the image, extracts GAN artifact patterns)

Spatial (1792) + Frequency (128) → Fusion MLP → 0 or 1 (real/fake)
```

**EfficientNet-B4** — a CNN pretrained on ImageNet. It looks at the visual/spatial parts of the image (textures, edges, blending artifacts).

**FFT Branch** — converts the image to frequency domain using Fast Fourier Transform. GAN-generated images leave repeating frequency patterns that are invisible to the eye but show up clearly in FFT. Two small conv layers process this.

**CBAM (Channel + Spatial Attention)** — sits on top of EfficientNet. It learns which feature channels and which spatial regions to pay attention to. Helps focus on the face area and ignore background.

**Grad-CAM** — not part of training, used only at inference. Creates the heatmap overlay by looking at which parts of the image most influenced the prediction.

---

### Dataset

**140k Real and Fake Faces**
- Source: Kaggle — `xhlulu/140k-real-and-fake-faces`
- Real images: ~70,000 photos from Flickr (real people)
- Fake images: ~70,000 generated by StyleGAN2
- Image size: 256×256, cropped to 224×224 during training
- Format: JPG, split into `train/` and `valid/` folders

**Important note:** This dataset contains GAN-generated face images (StyleGAN2), not face-swap deepfakes. It is good at detecting AI-generated faces but may behave differently on video face-swaps like FaceSwap or DeepFaceLab. For better face-swap detection, the model should be retrained on **FaceForensics++** or **DFDC** dataset.

Download command:
```bash
python ml/datasets/download.py
```
(Requires a Kaggle account and API key at `~/.kaggle/kaggle.json`)

---

### Training strategy

Training was done in **two phases** to avoid overfitting and speed things up:

**Phase 1 — Head only (5 epochs)**
- EfficientNet backbone is completely frozen (weights don't change)
- Only the FFT branch, CBAM, and final classifier layers are trained
- Learning rate: `3e-4`
- This is fast and teaches the new layers quickly

**Phase 2 — Fine-tune (5 epochs)**
- Last 3 blocks of EfficientNet are unfrozen
- Backbone gets a low learning rate (`3e-5`) so it doesn't forget ImageNet knowledge
- Head keeps higher rate (`3e-4`)
- Cosine annealing scheduler on both phases

**Loss function:** Binary Cross-Entropy with Logits (`BCEWithLogitsLoss`)

**Optimizer:** AdamW with weight decay `1e-4`

**Data augmentation during training:**
- Random resized crop (80–100% of image)
- Random horizontal flip
- Color jitter (brightness, contrast, saturation, hue)
- Random grayscale (2% probability)
- ImageNet normalization (mean `[0.485, 0.456, 0.406]`, std `[0.229, 0.224, 0.225]`)

### Hardware and time

| Hardware | Time |
|---|---|
| Apple M2 Pro (MPS) | ~50–70 minutes |
| NVIDIA GPU (CUDA) | ~20–30 minutes |
| CPU only | ~4–6 hours |

Config used:
- Batch size: 64
- Training images: 20,000 real + 20,000 fake (capped per class)
- Validation images: 5,000 real + 5,000 fake

---

### How to run training

```bash
# From the deepshield root folder
cd deepshield/backend
source venv/bin/activate          # Mac
# or: venv\Scripts\activate       # Windows

python ../ml/training/train.py
```

Weights are saved to `backend/models/deepshield_b4.pth` whenever validation accuracy improves.

---

### Key files

| File | What it does |
|---|---|
| `ml/models/deepshield.py` | Main model class — wires backbone + FFT + CBAM + classifier |
| `ml/models/fft_branch.py` | FFT frequency branch (runs on CPU for MPS compatibility) |
| `ml/models/cbam.py` | Channel and spatial attention module |
| `ml/datasets/deepfake_dataset.py` | Dataset loader — reads `train/real/`, `train/fake/` folders |
| `ml/datasets/download.py` | Downloads the Kaggle dataset |
| `ml/training/train.py` | Full training script with two-phase strategy |
| `ml/inference/gradcam.py` | Grad-CAM heatmap generation at inference time |
| `backend/models/deepshield_b4.pth` | Saved weights (not in git, add manually) |

## Audio Deepfake Model

### Architecture

```
Audio file (4 seconds at 16kHz)
        │
        ├──► Mel spectrogram (128×128)
        │         └──► EfficientNet-B0 backbone → 1280-dim features
        │
        └──► Raw waveform
                  └──► FFT → Conv1D branch → 128-dim features

Spectrogram (1280) + Waveform FFT (128) → Classifier → real/fake
```

**Mel spectrogram** — a visual representation of sound frequencies over time. EfficientNet-B0 treats it like an image and learns patterns from it.

**FFT + Conv1D** — the raw audio waveform is transformed to frequency domain (1D FFT), then two 1D conv layers extract temporal-frequency patterns.

---

### Dataset

**ASVspoof 2019 — Logical Access (LA) subset**
- Source: `https://datashare.ed.ac.uk/handle/10283/3336`
- Real speech: recordings of real human speakers
- Fake speech: generated by 17 different TTS and voice conversion systems
- Format: FLAC audio files, 16kHz, mono

Put the downloaded data at:
```
deepshield/data/asvspoof2019/LA/
    ASVspoof2019_LA_train/flac/
    ASVspoof2019_LA_cm_protocols/ASVspoof2019.LA.cm.train.trn.txt
```

---

### How to run audio training

```bash
python ml/training/train_audio.py
```

Weights are saved to `backend/models/deepshield_audio.pth`.

**Note:** Without trained weights, the audio endpoint returns `label: UNKNOWN` with a message saying to run training. The image and video detection still works fine.

## ViT Alternative Model

As an alternative to the custom EfficientNet model, DeepShield supports a ViT (Vision Transformer) model from HuggingFace:

- Model: `dima806/deepfake_vs_real_image_detection`
- Fine-tuned ViT-base-patch16 on real deepfake data
- Downloads ~340MB automatically on first use
- No `.pth` file needed — cached at `~/.cache/huggingface`

Switch to it by changing `.env`:
```
MODEL_BACKEND=vit
```

The ViT model tends to be more accurate on face-swap deepfakes since it was trained on that type of data. The custom EfficientNet model is better at detecting pure AI-generated faces (StyleGAN2 etc).

---

## Notes on accuracy

The current EfficientNet model was trained on StyleGAN2 faces. You may notice:

- **AI-generated faces** (Midjourney, DALL-E, StyleGAN) → detected well
- **Face-swap videos** (like the Tom Cruise TikTok deepfakes) → may not detect reliably
- **Real Instagram photos** → should show as REAL with high confidence
- **Screenshots of real faces** → should show as REAL

If you need better face-swap detection, switch to `MODEL_BACKEND=vit` or retrain on FaceForensics++.
